# WhatsApp AI Group Chat Summarizer

An AI-powered WhatsApp-style group chat application that analyzes large group conversations and generates a structured, easy-to-understand summary.

The project is designed to demonstrate how AI can help users quickly understand important discussions, decisions, questions, topics, and key information from lengthy group conversations.

## 🚀 Features

### 💬 WhatsApp-Style Chat Interface
- Clean and familiar WhatsApp-inspired interface
- Individual and group conversations
- Realistic group chat experience
- Message timestamps and member information
- Unread message indicators

### 🤖 AI-Powered Chat Summarization
- Summarizes lengthy group conversations
- Identifies important topics and discussion threads
- Extracts key decisions and relevant information
- Detects important questions and discussions
- Generates a structured summary for easier reading

### 📌 Structured AI Summary
The generated summary organizes conversation insights into multiple sections, including:

- What is the conversation about?
- Important topics
- Key discussions
- Decisions made
- Questions raised
- Important dates and deadlines
- Action items
- People involved
- Important messages
- Overall summary

### 🔎 View Source
- Every extracted insight can be traced back to the original conversation
- "View Source" functionality helps verify where information came from
- Clicking a source takes the user directly to the relevant message

### 📱 Responsive Design
- Desktop-friendly interface
- WhatsApp-inspired visual design
- Responsive layout for different screen sizes

## 🧠 AI Demonstration

The project includes a realistic group conversation containing **427 messages** between multiple group members.

The main demonstration group is:

**College Project Team**

The conversation represents a realistic academic project discussion involving topics such as:

- Project development
- Architecture decisions
- Technical issues
- WebSocket bug fixes
- Presentation preparation
- Speaking order
- Venue changes
- IEEE formatting
- Project submission

The summarization workflow presents multiple stages such as:

1. Analyzing the conversation
2. Finding important topics
3. Detecting dates, venues, questions and decisions
4. Preparing the structured summary
